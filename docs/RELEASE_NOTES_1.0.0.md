# Amarin 1.0.0

The first public showcase release of Amarin, a native SwiftUI food-expiry companion powered by Gemini AI.

## Highlights

- Native iOS experience with adaptive Liquid Glass presentation.
- Japanese and English interfaces with automatic system appearance support.
- Expiry-first food dashboard and local reminder scheduling.
- Gemini-powered package analysis and conversational product registration.
- AI Kitchen recipe generation using registered, non-expired ingredients.
- Follow-up AI chef chat for substitutions and cooking guidance.
- Points, lifetime XP, levels, themes, badges, effects, and reward details.
- Food-waste penalties that reduce spendable points without erasing lifetime XP.

## Reliability

- Prevents notification preference initialization from overwriting previously stored food records.
- Verified with an unsigned iOS Simulator build using Xcode 27.1.
